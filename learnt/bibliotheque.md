# Bibliothèque de cours (NotebookLM, lecture seule)

> Les carnets NotebookLM de cours de l'apprenant. L'archiviste les consulte au diagnostic, pour les rappels et pour les quiz, mais n'y écrit **jamais**. Règles : `.agents/agents/archiviste.md`, section "La bibliothèque de cours".

## Une source secondaire

Les cours sont des PDF datés de moins d'un an au moment où la bibliothèque a été constituée (2026-11), et certains points ont pu changer depuis (versions de Spring Boot, d'Hibernate, de Java). Quand un détail compte (annotation, configuration, comportement par défaut), le mentor le vérifie dans la documentation officielle **de la version fixée au cadrage**. Un écart entre le cours et la réalité est une occasion d'apprendre : on le note.
