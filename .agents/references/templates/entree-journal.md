   (message, extrait de stack trace, code HTTP ou comportement observé)

2. **Contexte** : ce que je faisais, ce que j'attendais.
3. **Pourquoi (cause racine)** :
4. **Démarche** : comment je l'ai trouvée (logs, debugger, hypothèses testées).
