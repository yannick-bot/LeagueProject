# LeaguePlatform API

Projet d'apprentissage backend Java / Spring Boot, conduit avec le kit d'apprentissage guidé du dossier `.agents/` (voir `.agents/README.md`).

- **Agent à utiliser** : `mentor` (panneau `/agents`).
- **État du projet** : `docs/` (cadrage, modèle, contrat) et `learnt/` (concepts, journal d'erreurs, compétences).
- **Typographie** : jamais de tiret cadratin ; utiliser `-`, `:` ou des parenthèses.
