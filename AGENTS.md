# LeaguePlatform API

Projet d'apprentissage backend Java / Spring Boot, conduit avec le kit d'apprentissage guidé du dossier `.agents/` (voir `.agents/README.md`).

- **Agent à utiliser** : `mentor` (panneau `/agents`).
- **État du projet** : `docs/` (cadrage, modèle, contrat, progression).
- **Mémoire d'apprentissage** : `.memoire/`, dépôt Git à part, commun à tous les projets (grille, journal et mémo d'erreurs, fiches concept, bibliothèque de cours). Il est ignoré par ce dépôt : pour y chercher, vise toujours ce dossier explicitement.
- **Typographie** : jamais de tiret cadratin ; utiliser `-`, `:` ou des parenthèses.
